1. Core Python Fundamentals

01What is the GIL? How does it affect multithreading?+
Answer

The GIL is a mutex in CPython allowing only one thread to execute Python bytecode at a time. It exists to protect reference-counting memory management from race conditions.

Impact: CPU-bound multithreaded code gets no real parallelism. Threads still help for I/O-bound tasks (network, file, DB) because the GIL is released during I/O.

Solutions: multiprocessing for CPU-bound, asyncio for I/O-bound, or PySpark for distributed processing.

"At Citadel, our ML pipelines were CPU-intensive so we used PySpark — each executor runs in its own process, sidestepping the GIL entirely."

02Mutable vs Immutable types — what are they and why does it matter?+
Answer

Mutable: list, dict, set — changed in-place. Immutable: int, str, tuple, frozenset — any change creates a new object.

Why it matters: 1) Mutable default argument bug: def f(x=[]) shares one list across calls. 2) Only immutable types can be dict keys or set members. 3) Passing a mutable object to a function lets the function modify the caller's data.

03Explain decorators. How do they work internally?+
Answer

A decorator takes a function, wraps it with extra behavior, and returns the modified function. @my_dec above def func() is syntactic sugar for func = my_dec(func).

Use cases: Logging, auth, caching (@functools.lru_cache), timing, retry logic, input validation. FastAPI's @app.get() is itself a decorator.

"At EY, I used decorators for request logging on FastAPI endpoints. I also used @lru_cache to cache expensive DB lookups in clinical pipelines."

04List comprehension vs Generator expression — difference?+
Answer

List comp [x for x in range(n)] — creates entire list in memory. Generator (x for x in range(n)) — produces values lazily, one at a time, minimal memory.

Use generators for large/streaming data. Use lists when you need random access or multiple iterations.

"In EY's healthcare pipelines, I used generator patterns for streaming CSV processing before passing to PySpark — avoiding loading full files into driver memory."

05How does Python memory management work?+
Answer

Python uses a private heap managed by the memory manager. Two mechanisms: 1) Reference counting — each object tracks how many references point to it; freed immediately at zero. 2) Garbage collector (gc module) — handles circular references using generational collection (3 generations).

Python also does small object pooling — integers -5 to 256 and short strings are cached (interning).

06Explain *args and **kwargs+
Answer

*args collects extra positional args into a tuple. **kwargs collects extra keyword args into a dict. They make functions flexible to accept variable arguments.

Order: def f(regular, *args, keyword_only, **kwargs)

Common use: Decorators (wrapping any function), forwarding to parent __init__, flexible API wrappers.

07Deep copy vs Shallow copy+
Answer

Shallow (copy.copy()) — new outer object, shared references to nested objects. Deep (copy.deepcopy()) — recursively copies everything, fully independent at all nesting levels.

Matters when working with nested structures (list of dicts, config objects). For flat data, shallow copy is fine and faster.

08What are generators and the yield keyword?+
Answer

A generator function uses yield instead of return. It returns a generator iterator — execution pauses at yield and resumes on next().

Key benefit: Lazy evaluation. 10 million items uses same memory as 10. Perfect for large files, infinite sequences, data pipeline stages.

09How is Python's pass-by-assignment different from pass-by-reference/value?+
Answer

Python uses pass-by-object-reference (sometimes called "pass-by-assignment"). The function receives a reference to the same object, not a copy.

If the object is mutable (list, dict), modifications inside the function affect the original. If immutable (int, str), rebinding inside the function creates a new local object — the original is unchanged.

This is why def f(x): x.append(1) modifies the caller's list, but def f(x): x = x + 1 doesn't change the caller's integer.

10What is the difference between == and is?+
Answer

== checks value equality (calls __eq__). is checks identity — whether two variables point to the exact same object in memory.

[1,2] == [1,2] → True (same content). [1,2] is [1,2] → False (different objects). Use is only for singletons: x is None, x is True.

11What are Python virtual environments and why use them?+
Answer

An isolated Python installation with its own packages. Created via python -m venv or conda. Prevents dependency conflicts between projects. requirements.txt or pyproject.toml pins versions for reproducibility.

"At Citadel, we containerized each ML service with Docker + pinned requirements. Locally I use conda for managing CUDA dependencies with PyTorch."

12What is the difference between a module, package, and library?+
Answer

Module: A single .py file. Package: A directory of modules with an __init__.py. Library: A collection of packages (e.g., NumPy, Pandas). Framework: A library that dictates application structure (e.g., Django, FastAPI).

13Explain Python's scope rules (LEGB)+
Answer

Python resolves variable names in this order: Local → Enclosing (closure) → Global → Built-in.

global keyword lets you modify a global variable from inside a function. nonlocal lets you modify a variable from an enclosing scope (closures). Without these keywords, assignment creates a new local variable.

2. Object-Oriented Python

14What is self in Python? Why explicit?+
Answer

Reference to the current instance. Python makes it explicit (unlike Java's implicit this) following "explicit is better than implicit." It's convention — you could name it anything.

@classmethod uses cls (reference to class). @staticmethod takes neither.

15__init__ vs __new__ — what's the difference?+
Answer

__new__ is called first — creates and returns the instance. __init__ is called second — initializes it (sets attributes). You rarely override __new__ except for singletons or subclassing immutable types.

16Explain inheritance, multiple inheritance, and MRO+
Answer

Python supports multiple inheritance. Method Resolution Order (MRO) determines which parent's method is called — uses C3 linearization algorithm. Check with ClassName.__mro__ or ClassName.mro().

The diamond problem (two parents sharing a grandparent) is resolved by MRO — each class appears only once in the resolution chain. super() follows MRO, not just the immediate parent.

17What are @classmethod, @staticmethod, and instance methods?+
Answer

Instance method: Takes self, can access/modify instance state. Class method: Takes cls, can access/modify class state, often used as alternative constructors. Static method: Takes neither, just a utility function namespaced to the class.

18What are dunder/magic methods? Name some common ones.+
Answer

Methods with double underscores that Python calls implicitly. Common ones: __init__ (constructor), __str__ (human-readable string), __repr__ (developer string), __len__, __getitem__ (indexing), __eq__ (==), __hash__ (hashability), __enter__/__exit__ (context manager), __iter__/__next__ (iterator).

19What are abstract classes and ABCs?+
Answer

Abstract classes define interfaces — methods subclasses MUST implement. Use from abc import ABC, abstractmethod. You can't instantiate an abstract class directly.

Use case: When you want to enforce that all payment processors implement charge() and refund() methods.

20What are dataclasses? When would you use them?+
Answer

@dataclass (Python 3.7+) auto-generates __init__, __repr__, __eq__ from class attributes with type hints. Reduces boilerplate for data-holding classes.

Use when you need a class primarily for storing data. For immutable records, use @dataclass(frozen=True) or NamedTuple.

21What is @property and how does it work?+
Answer

@property lets you define methods that are accessed like attributes — providing controlled access with getter/setter/deleter. It enables validation, computed attributes, and encapsulation without changing the API.

Example: @property def age(self): return self._age then @age.setter def age(self, val): if val < 0: raise ValueError

3. Python Data Structures & Collections

22List vs Tuple — when to choose which?+
Answer

List: Mutable, for collections that change. Tuple: Immutable, for fixed records. Tuples can be dict keys, are slightly faster, use less memory. Choose tuple when data shouldn't change (coordinates, DB rows, function returns).

23What is a dict? How does it work internally?+
Answer

Dict is a hash table. Keys are hashed to determine bucket placement. Average O(1) for get/set/delete. Keys must be hashable (immutable). Since Python 3.7, dicts maintain insertion order.

Hash collisions are handled by open addressing (probing). If load factor gets too high, the table resizes (roughly doubles).

24Set operations and when to use sets+
Answer

Sets are unordered collections of unique elements backed by hash tables. O(1) membership testing. Support & (intersection), | (union), - (difference), ^ (symmetric difference).

Use when: Deduplication, fast membership checks, set math. Converting if x in my_list to if x in my_set turns O(n) → O(1).

25What is collections.defaultdict?+
Answer

A dict subclass that provides a default value for missing keys via a factory function — avoids KeyError. defaultdict(int) defaults to 0, defaultdict(list) defaults to [].

Use case: Counting (d[key] += 1) or grouping (d[key].append(val)) without checking if key exists.

"I use defaultdict constantly in Karat-style problems — grouping students by courses, counting badge accesses, aggregating domain visits."

26What is collections.Counter?+
Answer

A dict subclass for counting hashable objects. Counter("banana") gives {'a':3, 'n':2, 'b':1}. Has useful methods: most_common(n), arithmetic operations between Counters, elements().

Use case: Word frequency, character counting, finding most common elements.

27What is collections.deque?+
Answer

Double-ended queue with O(1) append/pop from both ends. Regular lists are O(n) for insert(0, x) or pop(0). Use deque for BFS queues, sliding windows, and maintaining fixed-size history with maxlen.

28What is a namedtuple?+
Answer

A tuple subclass with named fields. Point = namedtuple('Point', ['x','y']) → access via p.x instead of p[0]. Immutable, lighter than classes, great for records/structured data.

Modern alternative: typing.NamedTuple with type hints or @dataclass(frozen=True).

29Time complexity of common Python operations+
Answer

List: Index O(1), append O(1), insert/delete O(n), search O(n), sort O(n log n).

Dict: Get/set/delete O(1) avg, O(n) worst. Iteration O(n).

Set: Add/remove/contains O(1) avg. Union/intersection O(m+n).

deque: Append/pop both ends O(1). Index access O(n).

The key interview insight: switching from list to set/dict for lookups often converts O(n²) to O(n).

4. Advanced Python Concepts

30Explain exception handling (try/except/else/finally)+
Answer

try: risky code. except ExceptionType: handle specific errors. else: runs only if NO exception. finally: ALWAYS runs (cleanup). Best practice: catch specific exceptions, use custom exception classes.

"At EY, I created custom exceptions like ClinicalDataValidationError with HTTP status mappings in FastAPI exception handlers."

31Multithreading vs Multiprocessing — when to use which?+
Answer

Threading: Shared memory, good for I/O-bound (API calls, file I/O). Limited by GIL for CPU work. Multiprocessing: Separate memory/GIL per process, good for CPU-bound (ML, data transforms). Higher overhead.

Third option: asyncio for high-concurrency I/O with a single thread (event loop).

"At Citadel I used PySpark for CPU-heavy batch inference (multiprocessing across executors), and async/await in FastAPI services for non-blocking DB calls."

32What is asyncio and async/await?+
Answer

asyncio is Python's built-in async I/O framework using an event loop. async def defines a coroutine. await yields control back to the event loop while waiting for I/O.

Single-threaded but handles thousands of concurrent connections. FastAPI is built on top of asyncio. Great for microservices, web scraping, chat applications.

33What are context managers and the 'with' statement?+
Answer

Handle setup/teardown automatically. Implement __enter__ and __exit__. Guarantees cleanup even on exceptions. Most common: with open("file") as f:. Also useful for DB connections, locks, temp directories.

Can create with @contextmanager from contextlib using a generator with a single yield.

34What are closures in Python?+
Answer

A closure is an inner function that remembers and has access to variables from its enclosing scope, even after the outer function has returned. The enclosed variable is "closed over."

Closures are the foundation of how decorators work. They're also used for factory functions, callbacks with state, and data encapsulation.

35What are lambda functions?+
Answer

Anonymous, single-expression functions: lambda x: x * 2. Useful as short callbacks for sorted(), map(), filter(), pandas .apply(). Limited to one expression — use named functions for complex logic.

36What are type hints? Why use them?+
Answer

Optional annotations: def greet(name: str) -> str:. Not enforced at runtime. Benefits: IDE autocompletion, mypy catches bugs statically, serves as docs, makes large codebases navigable. FastAPI uses them for automatic request validation.

37What is the walrus operator (:=)?+
Answer

Python 3.8+. Assigns and returns a value in one expression: if (n := len(a)) > 10: print(n). Useful in while loops (while (line := f.readline())) and list comprehensions to avoid redundant computation.

38What are iterators and the iterator protocol?+
Answer

An iterator implements __iter__() (returns self) and __next__() (returns next value or raises StopIteration). Every generator is an iterator. for loops internally call iter() then repeatedly call next().

You can make any class iterable by implementing the iterator protocol.

39What are slots and when would you use them?+
Answer

__slots__ restricts an object's attributes to a predefined set, replacing the instance __dict__ with a fixed-size array. Saves ~40% memory per instance and slightly faster attribute access. Use when creating millions of small objects.

40What is monkey patching?+
Answer

Dynamically modifying a class or module at runtime. Example: replacing a method on a third-party class to fix a bug without modifying source. Powerful but dangerous — makes code harder to debug. Common in testing (mocking).

5. Performance & Optimization

41How do you profile Python code?+
Answer

cProfile: Built-in profiler showing function call counts and time. timeit: Microbenchmarking. line_profiler: Line-by-line timing. memory_profiler: Memory usage per line.

Workflow: profile → identify hotspot → optimize that specific function → re-profile.

42Common Python performance pitfalls?+
Answer

1) String concatenation in loops (use join()). 2) in on lists instead of sets (O(n) → O(1)). 3) Nested loops when a hash map would work. 4) Loading entire files into memory (use generators). 5) Using Python loops when NumPy vectorization exists. 6) Not using built-in functions (C-implemented, faster).

43What is functools.lru_cache?+
Answer

A decorator that caches function results based on arguments (memoization). LRU = Least Recently Used eviction. Dramatically speeds up recursive functions (fibonacci from O(2^n) to O(n)). Use @lru_cache(maxsize=128). Arguments must be hashable.

44When would you use NumPy over pure Python?+
Answer

NumPy operates on contiguous C arrays, enabling vectorized operations that avoid Python loop overhead. 10-100x faster for numerical computation. Use for matrix math, statistical operations, any batch numeric processing.

"In our ML pipelines, all feature engineering uses NumPy/Pandas vectorization — never Python loops over data rows."

6. Testing, Debugging & Best Practices

45How do you test Python code? What frameworks?+
Answer

pytest: Most popular — simple syntax, fixtures, parametrize, plugins. unittest: Built-in, class-based. Types: Unit tests (single function), integration tests (components together), e2e tests (full workflow).

Mocking with unittest.mock — replace external dependencies (DB, API calls) with mock objects.

"At Citadel, I wrote pytest suites for our API endpoints and ML pipeline stages, using fixtures for test data and mocking external service calls."

46What is PEP 8? Why follow it?+
Answer

Python's official style guide. Covers naming (snake_case for functions, PascalCase for classes), indentation (4 spaces), line length (79-120 chars), imports ordering. Enforced with linters like flake8, black (formatter), ruff (fast linter).

Consistent style makes code readable across teams and reduces cognitive load during code reviews.

47How do you debug Python code?+
Answer

pdb / breakpoint() (Python 3.7+): Interactive debugger. logging module: Structured logging with levels (DEBUG, INFO, WARNING, ERROR). IDE debuggers (VS Code, PyCharm). print() for quick checks but never in production.

"At Infosys, I diagnosed defects through unit testing, logging, root cause analysis, and systematic debugging — reducing critical bugs by 30%."

48What are docstrings and why are they important?+
Answer

String literals as the first statement in a module/class/function. Accessed via __doc__. Formats: Google style, NumPy style, reStructuredText. Tools like Sphinx auto-generate docs from docstrings. They're living documentation that stays with the code.

7. GenAI, LLMs & Machine Learning

49What is RAG (Retrieval-Augmented Generation)? How did you implement it?+
Answer

RAG combines a retrieval system (vector DB search) with a generative LLM. Instead of relying on training data alone, you retrieve relevant documents and pass them as context to generate grounded, factual answers.

Pipeline: Query → Embed → Search vector DB (ChromaDB, FAISS, Pinecone) → Top-k chunks → Inject into prompt → LLM generates answer with source attribution.

"At Citadel, I prototyped a RAG system using LangChain + Vector DB + OpenAI. I chunked internal docs with overlap, embedded with OpenAI embeddings, stored in a vector store. The LLM answered enterprise questions with sourced references."

50Fine-tuning vs RAG — when to choose which?+
Answer

Fine-tuning: Re-trains model weights. Changes behavior/style. Expensive, needs labeled data, requires retraining on updates. RAG: Base model + external knowledge at inference time. Cheaper, dynamic, better source attribution.

Choose fine-tuning for style/tone changes, domain-specific language. Choose RAG for frequently changing knowledge, source attribution, data privacy. LoRA/QLoRA: parameter-efficient fine-tuning — trains small adapter layers, dramatically reducing compute.

51Explain prompt engineering techniques+
Answer

Crafting LLM inputs for desired outputs. Techniques: 1) System prompts (set role/context). 2) Few-shot examples (input-output pairs). 3) Chain-of-thought (step-by-step reasoning). 4) Constraints ("Answer in JSON", "Only use provided context"). 5) Temperature tuning for creativity vs consistency.

"In our RAG system, I designed prompts instructing the LLM to only answer from retrieved context and cite source documents — reducing hallucinations significantly."

52What is LangChain and why use it?+
Answer

Python framework for LLM applications. Provides: Chains (sequential LLM calls), Agents (LLMs choosing tools dynamically), Retrieval (vector store integration), Memory (conversation context). Lets you swap providers without rewriting code.

"I used LangChain's RetrievalQA chains at Citadel and LangChain agents in my Agentic Medical Intelligence project for multi-tool orchestration."

53What are vector databases and embeddings?+
Answer

Embeddings: Dense numerical vectors representing text semantically — similar meanings have nearby vectors. Generated by models like OpenAI ada-002, sentence-transformers.

Vector DBs (FAISS, ChromaDB, Pinecone, Weaviate): Optimized for similarity search (cosine similarity, approximate nearest neighbors). Store embeddings + metadata for RAG retrieval.

54What are Transformers? How do attention mechanisms work?+
Answer

Transformers process sequences in parallel (unlike RNNs). Core innovation: self-attention — each token attends to all others, learning which words are relevant to each other. Q (query), K (key), V (value) matrices compute attention scores.

Multi-head attention: Multiple attention heads capture different relationships. Encoder (BERT-style, bidirectional) for understanding. Decoder (GPT-style, autoregressive) for generation.

55What is Hugging Face and how have you used it?+
Answer

Hugging Face is the largest hub for open-source ML models + the transformers library. Provides pre-trained models, tokenizers, pipelines for NLP, vision, audio. from transformers import pipeline; p = pipeline("sentiment-analysis") — production inference in 2 lines.

Also: datasets library, accelerate for distributed training, model hosting via Inference API.

56What is MLflow and why use it?+
Answer

Open-source platform for ML lifecycle management: Tracking (log params, metrics, artifacts), Projects (reproducible runs), Models (model registry, versioning), Serving (deploy models as REST APIs).

"At Citadel, I used MLflow for model versioning and tracking experiments. It made it easy to compare model runs and roll back if a new version degraded performance."

57What is responsible AI and AI compliance?+
Answer

Building AI that is fair, transparent, accountable, safe. Concerns: Bias (audit training data), Hallucination (RAG + guardrails), Data privacy (PII protection, GDPR), Explainability (especially in regulated industries like banking).

For Citi: financial regulations require model decisions to be explainable and auditable. No black-box decisions on credit or fraud.

"At Citadel, I ensured responsible AI adoption — validation checks, audit trails, no PII in training data."

58What is Agentic AI?+
Answer

AI systems that can autonomously plan, execute, and adapt using tools. Unlike simple chat, agents decide which tools to call (search, calculator, DB query, API), execute multi-step workflows, and handle errors.

Frameworks: LangChain Agents, AutoGPT, CrewAI. Key components: LLM (brain), tools (capabilities), memory (context), planning (reasoning).

"My Agentic Medical Intelligence project used an agentic RAG system orchestrating Google Search + Vector DB tools to automate medical report analysis."

59Explain feature engineering in ML pipelines+
Answer

Transforming raw data into informative features for models. Techniques: encoding categoricals (one-hot, label), scaling numerics (StandardScaler, MinMax), creating interaction features, handling missing values, text vectorization (TF-IDF, embeddings), time-based features (day-of-week, lag).

"In my financial analysis project, I fused ML-driven sentiment scores with historical time-series features (moving averages, volatility, lag features) for automated financial analysis."

60PyTorch vs TensorFlow — differences and when to use each?+
Answer

PyTorch: Dynamic computation graph (define-by-run), Pythonic, dominant in research and GenAI. TensorFlow: Static graph (define-and-run, though eager mode exists), stronger in production/mobile deployment, TensorFlow Serving.

Trend: PyTorch has become dominant in research and increasingly in production. Most Hugging Face models are PyTorch-first. Use whichever the team uses.

9. Code Analysis / "What's Wrong?" Questions

66Bug: def append_to(item, target=[])+
Answer

Mutable default argument. The [] is created once at function definition, shared across all calls. Fix: def append_to(item, target=None): if target is None: target = []

67Performance: string += in a loop+
Answer

Strings are immutable — each += creates a new object, copies everything. O(n²) for n iterations. Fix: collect in a list, "".join(parts) at the end — O(n).

68Performance: "if x in my_list" inside a loop+
Answer

in on list is O(n). Inside a loop of m items = O(m×n). Fix: my_set = set(my_list), then if x in my_set is O(1). Total: O(m+n). This is the #1 optimization pattern in coding interviews.

69What does this print? x=[1,2,3]; y=x; y.append(4); print(x)+
Answer

[1, 2, 3, 4]. y = x creates another reference to the same list. Both names point to one object. Fix: y = x.copy() or y = x[:].

70Bug: late binding closure in loop+
Answer

funcs = [lambda: i for i in range(5)] — all return 4! Closures capture the variable i by reference, not its value. By loop end, i is 4 for all. Fix: lambda i=i: i (default argument captures current value).

71What's wrong: except Exception: pass+
Answer

Silent failure. Catches every exception and does nothing — bugs are hidden, making debugging nearly impossible. Always log the exception, catch specific types, and handle appropriately. Never use bare except: pass in production.

72Performance: repeatedly calling len() in a loop condition+
Answer

Actually, len() on built-in types is O(1) in Python — the length is stored as an attribute, not recalculated. So this is NOT a performance issue (unlike some other languages). Good to know so you don't "fix" something that isn't broken — shows depth of knowledge.

73What does "import this" output?+
Answer

The Zen of Python — 19 guiding principles. Key ones: "Explicit is better than implicit", "Simple is better than complex", "Readability counts", "Errors should never pass silently", "There should be one obvious way to do it."
